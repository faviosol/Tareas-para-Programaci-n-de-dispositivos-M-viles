## Práctica: Interfaces Estáticas en Flutter

### Descripción
Diseño y maquetación de una aplicación móvil personal utilizando Flutter. La aplicación cuenta con 3 pantallas completamente estáticas orientadas al diseño de interfaces limpias mediante el uso de widgets fundamentales.

### Pantallas Incluidas
* **Pantalla de Inicio:** Bienvenida al usuario con un diseño centralizado y un botón de acción.
* **Pantalla de Perfil:** Presentación de datos personales, fotografía enlazada desde internet y datos de contacto con iconos.
* **Pantalla de Hobbies:** Lista estructurada con las actividades favoritas utilizando filas y columnas.

### Tecnologías y Widgets Utilizados
* **Framework:** Flutter & Dart
* **Widgets Estructurales:** `MaterialApp`, `Scaffold`, `AppBar`, `Padding`, `Center`
* **Widgets de Diseño:** `Column`, `Row`, `SizedBox`
* **Widgets de Contenido:** `Text`, `Icon`, `Image.network`, `ElevatedButton`
